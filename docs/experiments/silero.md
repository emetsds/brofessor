# Второй движок озвучки и исправления после KISS-ревью

Состояние: 01.11.2026. Apple Silicon Mac, Python 3.12.13. Только синтетический учебный отчёт о мосте; настоящие LLM и пользовательские источники не вызывались.

## Что изменено и проверено

- Новые download jobs сохраняют источник, точную ревизию и манифест файлов при submit. Offline-проверки изменяют каталог до выполнения и между ошибкой/продолжением: job скачивает исходную ревизию. Прежние ссылки и общий установленный snapshot Qwen продолжают разрешаться. Старые jobs только с ID не позволяют восстановить не записанную историческую ревизию.
- Аудиозадания сохраняют снимок модели, голосов и настроек. Повтор request key возвращает исходное задание, включая старый формат без снимка. UI различает ревизии одного ID; другой запрос со старым ключом отклоняется.
- Неизвестные generation/render kinds завершаются явной ошибкой до обращения к модели.
- `speech.py` содержит два конкретных локальных движка. Очередь, контроль WAV, сегментный кеш и монтаж остаются общими. Каталог управляет голосами и языками, UI/CLI используют общий сервис.

## Silero CIS Base

Официальные [описание и пример](https://github.com/snakers4/silero-models#v5-cis-base-models), [MIT](https://github.com/snakers4/silero-models/blob/master/LICENSE_CIS). Вес скачан с `https://models.silero.ai/models/tts/ru/v5_cis_base.pt` через настоящую очередь; размер **91 680 514 байт**. SHA-256 **`ba41b18f6a707ad93605a162998865e7c087153d2e010a26dd02229dab0e672a`** закреплён в каталоге. PyTorch **2.15.0**, CPU, четыре потока, 48 кГц; голоса `ru_roman` / `ru_zhadyra`.

HTTP-загрузка проверяет размер и SHA-256 до установки. Контрактные проверки покрывают прерывание, Range resume, изменение каталога, неверные веса и завершённый `.part` без сети. Неизменный установленный файл не перечитывается при каждом UI poll: ограниченный кеш хеша учитывает путь, размер, mtime и ctime; после изменения файл снова проверяется.

CIS Base подключена только для русского. Автоматических ударений нет: используется ручная разметка `+` перед ударной гласной. Цифры, латиница и неподдержанные символы переписываются русскими словами: собственная обработка модели может удалять их. Сервис и рендер отвергают такие входы; английский черновик не ставится в очередь Silero. Это не автоматическая замена Qwen для произвольного черновика.

## Настоящий диалог через worker

Восемь реплик, два голоса, общий синтетический источник. Qwen читает первую редакцию, Silero — вторую редакцию с теми же словами и ручной разметкой ударений.

| Модель | Готовое аудио, с | Рендер, с | Job |
|---|---:|---:|---|
| Qwen3 0.6B | 108.63 | 76.769 | `63270d2787d14bf8` |
| Qwen3 1.7B | 136.23 | 51.736 | `cffe7a2f7a164c17` |
| Silero CIS Base | 84.00 | 1.356 | `ef58d4aacebd476d` |

Это один smoke test, включая загрузку/прогрев движков; не сравнительный бенчмарк. Все три MP3 полностью декодированы FFmpeg. Повторная сборка Silero переиспользовала **8/8** сегментов, заняла **0.29 с** и сохранила длительность **84 с**. Цель две минуты не подменялась растяжением: предупреждения об отличающейся длительности сохранены.

В браузере проверены выбор Silero, русский текст требований/ограничений, статус установки, сохранённая модель задания и плеер. Автотесты включают выбор/скачивание обоих семейств через UI и общий service API. Итог: **218 тестов**, Ruff и `git diff --check` проходят. Реальные веса и аудио остаются вне Git.

Качество произношения требует прослушивания. Целая книга, серии и выпуски на 20–60 минут остаются в M2. Расширенный контракт слайдов и метаданные текстового исполнения не менялись в этом шаге.
