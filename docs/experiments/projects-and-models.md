# Проекты и выбор моделей речи

Проверено 01.11.2026 на Apple M4 / 32 GB, Python 3.12.13, MLX-Audio 0.6.3. Использованы собственные синтетические материалы о мосте; вызовов облачных текстовых моделей не было.

## Проекты

Один проект соответствует одному существующему workspace с SQLite и относительными путями файлов. Реестр имён, внешняя папка проектов, последний выбор и язык UI хранятся в пользовательских настройках. CLI поддерживает `project create/list/open/use`; `-w` и переменная `BROFESSOR_WORKSPACE` сохраняют явный выбор каталога.

Offline-проверки подтвердили создание вне checkout, изоляцию источников/заданий/результатов двух проектов, перенос закрытого workspace с повторным открытием, сохранность исходников и отказ от перезаписи существующей папки. AppTest проверил создание и переключение, повторное открытие и несохранённый буфер черновика при переходе между проектами.

В настоящем браузере создан проект в `/private/tmp/brofessor-projects-ui-qa/projects`, открыт существующий медиа-пилот, проверены отдельные списки источников и результатов. После reload выбранный проект и TTS-модель восстановились.

## Установка моделей

Каталог `speech_models.json` закрепляет репозиторий, revision и размер каждого необходимого файла. Установленные веса общие для проектов и находятся в пользовательском каталоге данных `brofessor/models/hub` вне приложения.

| Модель | Revision | Размер файлов | Реальная установка |
|---|---|---:|---|
| Qwen3-TTS 0.6B CustomVoice 4-bit | `08c72cad5e2fd0f41730c8bd1f28149585e46361` | 1 693 602 151 байт | Завершённый прежний снимок переиспользован, файлы размещены в общем каталоге |
| Qwen3-TTS 1.7B CustomVoice 4-bit | `f35faf19b0cc2160865af64ecf0f22f83d335135` | 2 312 056 829 байт | Скачивание через фоновое задание завершилось за 142 с |

Скачивание вызывается из UI или `tts download MODEL_ID --wait`, а `tts use` задаёт модель для следующих сборок. Worker хранит прогресс загрузки в проекте, веса переиспользуются между проектами. Offline-тесты проверяют прерванное скачивание и возобновление после нового открытия проекта, отмену, неполные/повреждённые файлы и закрепление выбранной модели в задании.

Основания каталога: [0.6B model card](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-0.6B-CustomVoice-4bit), [1.7B model card](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-4bit), [официальный механизм скачивания и кеша](https://huggingface.co/docs/huggingface_hub/guides/download). Обе карточки указывают Apache-2.0; размеры и revisions взяты из публичного API Hugging Face и подтверждены полным составом скачанных файлов.

## Настоящая озвучка

После установки весов worker был запущен с `HF_HUB_OFFLINE=1`. Через CLI `draft render --tts-model ... --wait` выполнены четыре двухголосых сборки с Ryan/Vivian. Сценарии подготовлены вручную для проверки: две короткие реплики о нагрузке вымышленного моста и отсутствии данных о наводнении.

| Модель | Язык | Длительность | Wall time |
|---|---|---:|---:|
| 0.6B | EN | 10.65 с | 32.63 с |
| 1.7B | EN | 10.41 с | 5.31 с |
| 0.6B | RU | 10.25 с | 4.12 с |
| 1.7B | RU | 11.13 с | 4.97 с |

Первый прогон включает холодный импорт библиотек. Все четыре MP3 полностью декодируются FFmpeg. Измерения этих коротких примеров подтверждают техническую совместимость и работу выбора модели. Прослушивание на ударения и качество тембра остаётся отдельной проверкой. Запрос длительности для тестовых заданий равнялся минуте; фактические короткие образцы правильно сохраняют предупреждение о расхождении. Выпуски 20–60 минут и качество целой книги остаются в M2.

Исходные результаты находятся вне Git: `/private/tmp/brofessor-model-pilot/speech-results.json`, JSON записей заданий, stderr и файлы аудио. Полная offline suite: 200 passed; Ruff check/format и наличие каталога моделей внутри wheel проверены.
