# Kokoro RU, Silero RU и RUAccent

02.11.2026. Пользователь одобрил подключение обеих моделей и пробу RUAccent после отрицательной оценки ударений Silero CIS и чрезмерной эмоциональности Qwen/F5. Это короткая техническая проверка и материал для выбора голосов. Слуховая приёмка M4 остаётся открытой.

## Что работает

В общий каталог, загрузчик, очередь, CLI и UI добавлены `kokoro-ru` и `silero-ru`. Веса установлены в общем пользовательском кеше. Настройки пользователя и прежние длинные выпуски не изменены. Новый UI использует прежний выбор модели; отдельного редактора пар голосов нет. Пресеты: Kokoro Dima / Sveta, Silero Aidar / Xenia. Для прослушивания отдельно записаны все три и все пять голосов соответственно.

| Компонент | Закреплённый источник | Объём |
|---|---|---|
| Kokoro RU, fp32 ONNX / CPU | `zaakirio/kokoro-ru@d649c57b239b18c4c384378127cbf01dba039bc1` | 662 784 382 байта |
| RUAccent, turbo3.1, полный словарь и rule engine | `ruaccent/accentuator@b78ae5ea1e62beaf138bed1865cd8c3b0b5ca855` | 726 405 787 байт |
| Silero RU v5.6 / CPU | официальный `v5_6_ru.pt`, SHA-256 `04cc9b1d08ce38bcaa9d02c488d80d3e6806d17f7eaa7c95982f36a3cbf50b2e` | 147 664 410 байт |

Для Kokoro есть отдельный extra `russian-speech`: RUAccent 1.5.8.3, ONNX Runtime 1.31.1, misaki 0.9.4, phonemizer 3.4.0, espeakng-loader 0.2.4. Точный граф закреплён в uv.lock. Полный Kokoro с английским spaCy не нужен. Копия фонетического frontend v2 атрибутирована в THIRD_PARTY_NOTICES; веса и ресурсы в Git не включены.

Kokoro получает IPA через рекомендованный авторами RUAccent → orthoepic respelling → acute-aware espeak → нормализацию v2. Оба ONNX checkpoint и три voicepack закреплены. Неизвестные фонемы и фразы длиннее 510 фонем вызывают ошибку с номером реплики; символы не отбрасываются и текст не обрезается. Предложения озвучиваются последовательно с точками отмены.

RUAccent не вызывается через его сетевой `load()`: компоненты инициализируются из полного установленного snapshot. Вспомогательный Koziev-код импортируется из отдельного пространства имён соответствующей ревизии, без записи в site-packages. Найден и исправлен реальный дефект: `Path(__file__).resolve()` указывает из HF-ссылки в blobs, где нет соседнего словаря. Общий загрузчик материализует пять небольших закреплённых Python-файлов рядом с их данными; веса и остальной кеш сохраняются. Исправлена также совместимость tokenizer v5 с обязательными `token_type_ids` в старых ONNX экспортах.

Подготовка не изменяет сохранённый сценарий. Ручной `+` или combining acute имеет приоритет, сохраняются исходные ё, регистр, пунктуация и пробелы. Изменение/потеря слов вызывает отказ реплики. Отдельный `synthesis_text` записывается в метаданные сегмента и аудио; ресурсные ревизии, версия подготовки и runtime участвуют в кеше. Повтор полностью кешированного аудио не загружает RUAccent или TTS.

В Silero RU по умолчанию включены официальные `put_accent`, `put_stress_homo`, `put_yo`, `put_yo_homo`, `stress_single_vowel`. Старые CIS snapshots не получают новых флагов. Сохранена проверка текста: числа и латинские имена нужно записывать русскими словами. Внешний RUAccent не включён для Silero автоматически: он испытывается отдельной парой записей с выключенными собственными accent/ё-флагами.

## Образцы

Все файлы лежат в `outputs/kokoro-silero-ru/`, которое исключено из Git. Полный текст находится в `source.json`: тот же авторский диалог из 75 слов / четырёх реплик, что в предыдущем сравнении. Каждый отдельный голос читает весь диалог. Без voice cloning, новых текстовых LLM-вызовов, эквалайзера или ускорения. Скорость Kokoro 1.0. WAV сохраняются вместе с MP3; между репликами — стандартная пауза рендера, между голосами в склейке — одна секунда.

| Плеер | Начало частей | Длительность |
|---|---|---|
| `kokoro-all-voices.mp3` | 0:00 Dima; 0:47.750 Sveta; 1:35.425 Masha | 2:22.775 |
| `silero-all-voices.mp3` | 0:00 Aidar; 0:40.300 Eugene; 1:12.588 Xenia; 1:47.775 Kseniya; 2:27.413 Baya | 3:07.013 |
| `silero-ruaccent-comparison.mp3` | 0:00 Aidar с родной обработкой; 0:40.300 Aidar с RUAccent | 1:18.262 |
| `kokoro-manual-stress.mp3` | Sveta: автоматическая реплика, затем та же с ручным `з+амке` | 0:26.550 |

Плееры с абсолютными локальными ссылками и отдельные записи — `listening-guide.md`; состав склеек и SHA-256 — `players.json`; полное декодирование и хеши MP3 — `decode-checks.json`. Подготовленный RUAccent текст сохранён в `source-ruaccent.json`. Условия экспериментальной Silero — `silero-ruaccent-spec.json`, ручной правки — `manual-stress-source.json`. У каждой отдельной записи есть `.audio.json` с сегментами и моделью.

RUAccent действительно ошибся в контексте «в старом замке»: результат `в ст+аром замк+е`, хотя здесь нужно `з+амке`. Ручная правка проверена реальным синтезом; подготовка сохранила её, остальные слова обработала автоматически. Поэтому наличие RUAccent не означает верные ударения во всём тексте. Выбор между встроенной Silero и внешней обработкой нельзя сделать по одному этому примеру или по ASR.

## Фактические проверки

На Apple M4 / 32 GiB настоящие модели сработали в общем рендере и через очередь: Silero job `efac36db3a014170`, Kokoro job `53884efe86dd4481`, авторский draft `c65096c1f6c247df` в изолированном QA workspace. Записи закономерно получают предупреждение о целевых 20 минутах. Повторное обращение через `service.render` возвращает прежние job ID. Основной проект, пользовательские defaults и сервисы не переключались.

RUAccent и первый Kokoro-диалог прошли с `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1` и запрещённым Python socket connect. Новых сетевых загрузок в синтезе нет. Приёмка не опирается на macOS telemetry/cache warnings сторонних библиотек: они не прервали работу. Ресурсы загружаются только явно через общий download.

Полное декодирование MP3 прошло. Локальный уже установленный Whisper base проверил 36 реплик: три Kokoro, пять Silero и Aidar+RUAccent, по четыре реплики. Максимальная непрерывная почти полная тишина — 1.16 с. Есть расхождения ASR в «Мэри Шелли», «атлас», окончаниях и границах слов. Они требуют прослушивания и не объявляются ни дефектами TTS, ни корректным произношением. ASR не различает надёжно нужные ударения, естественность, эмоциональность и утомительность. Результаты — `asr-checks.json` и `asr.log`.

Прошли 374 offline-теста, Ruff check/format и `git diff --check`. Тесты покрывают ручные ударения/ё и сохранность текста, отказ при удалении слов, tokenizer/ONNX contract, запрет фильтрации/обрезки фонем, версии подготовки и зависимости в кеше, кеш без загрузки, отмену/ошибку до checkpoint, прежний готовый файл, локализацию pinned helper-кода и точные native Silero flags с сохранением CIS. AppTest проверяет выбор и постановку скачивания обеих новых моделей через UI; обычный CLI видит установленные профили. Настоящий браузер отдельно в этом этапе не проверялся: изменения представления ограничены каталогом и переводом примечаний.

Источники: [Kokoro RU](https://huggingface.co/zaakirio/kokoro-ru), [RUAccent](https://github.com/Den4ikAI/ruaccent), [Silero](https://github.com/snakers4/silero-models). Лицензии весов: OpenRAIL / CC-BY-NC-SA-4.0 соответственно; RUAccent release metadata и текущая main-ветка декларируют разные лицензии, это отражено в THIRD_PARTY_NOTICES. Реальная проверка этого этапа — на Mac; Linux отдельно не испытывался. Длинный выпуск, лучшая пара голосов и полная слуховая приёмка ещё не подтверждены.

## Пятиминутное сравнение на книжном фрагменте

Следующий запрос пользователя 02.11.2026: один и тот же книжный фрагмент примерно на пять минут, с проверенными ударениями, для оценки утомительности. Выбрано начало [«Дамы с собачкой» Чехова, часть I](https://ilibrary.ru/text/976/p.1/index.html): от первого предложения до сообщения об имени Анны Сергеевны. Русский оригинал в общественном достоянии. Это чтение оригинала двумя голосами, без пересказа или новых реплик.

В `outputs/book-tts-comparison-2026-11-02/` сохранены исходная HTML-страница, её SHA-256/URL, исходный фрагмент, текст с ё и читаемыми названиями букв, фиксированная разметка ударений и `stress-review.json`. В финале 792 слова, 27 сегментов. Все 496 вхождений многосложных слов просмотрены в контексте; многосложные слова имеют явное ударение или ё. RUAccent использовался для черновой разметки; окончательные формы и имена проверены агентом вручную. Отдельно сверены `неразгово́рчив` по [Грамоте](https://gramota.ru/poisk?query=неразговорчивый&mode=slovari), `разнообра́зит` по [нормативному орфоэпическому словарю ИРЯ РАН](https://ruslang.ru/sites/default/files/doc/normativnyje_slovari/orfoepicheskij_slovar.pdf), `прожи́ть` по [Академосу](https://orfo.ruslang.ru/abc/part/pe?end=125657&start=125357). Прямое скачивание полного PDF словаря завершилось timeout; сверка соответствующей статьи выполнена по доступному индексированному тексту, полный PDF не объявлен прочитанным.

Единственные лексические нормализации для речи: `ъ` → «твёрдый знак» и `в С.` → «в городе Эс»; кроме этого восстановлены ё. Автоматически проверено, что остальной текст дословно совпадает с непрерывным оригиналом, а сборка сегментов не теряет и не переставляет слов. Обе модели получают один и тот же размеченный текст и одно распределение ролей. Повторный RUAccent pass в Kokoro отключён для этого экспериментального snapshot; её G2P получает проверенный текст напрямую. У Silero выключены native accent/ё-флаги. Каталожные defaults приложения сохранены.

| Запись | Голоса | Фактическая длительность |
|---|---|---|
| `kokoro-ru-5min.mp3` | Dima / Sveta | 5:40.025 |
| `silero-ru-5min.mp3` | Eugene / Kseniya | 4:31.175 |

Пары Dima/Sveta и Eugene/Kseniya выбраны пользователем. Скорость Kokoro 1.0, Silero — штатная. Время измерено по WAV; аудио не растягивалось. Фактическая длительность различается из-за естественного темпа моделей. Финальные render jobs `95c0f77ea5584009` / `feb1a340b02a486c`, авторский draft `b300ed37b8d24cfc`, редакция 1, с исходным фрагментом в собственной области источников. Сохранение проверено общим `service.edit_draft`, повтор render возвращает прежние job ID. Kokoro в окончательной сборке переиспользовал все 27 сегментов без загрузки модели; выбранная пара Silero записана заново. Предыдущие варианты и редакции сохранены.

Для сравнения громкость полных файлов выровнена только постоянным усилением; значения и измеренный результат MP3 сохранены в `loudness-and-files.json`. Kokoro измерен как −23.71 LUFS, вторая запись приводится к той же громкости. Эквалайзер, компрессор, удаление шума, изменение темпа и подрезание реплик не применялись. Исходные WAV/MP3 из worker сохранены.

Код приложения и зависимости в этом этапе не менялись; обычный suite заново не запускался. Фактическая проверка включает общий worker, сверку входных текстов/настроек, полное декодирование обеих финальных MP3 и локальный Whisper на всех 54 сегментах. Максимальная непрерывная почти полная тишина — 1.18 с. Есть расхождения ASR в именах, окончаниях и коротких фразах; они записаны в `asr-checks.json`, качество ударений из распознавания не выводится. Утомительность и полная слуховая приёмка M4 остаются открытыми до обратной связи пользователя.
