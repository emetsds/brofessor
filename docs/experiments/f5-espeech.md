# F5-TTS v1 и ESpeech RL-V2

01.11.2026. Apple Silicon Mac, Python 3.12.13, F5-TTS 1.1.22, Torch 2.15.0 / torchaudio 2.11.1, Metal. Пользователь уточнил, что ESpeech означает RL-V2.

## Реализация

Два каталожных пресета одного движка `f5`: F5 v1 для английского и ESpeech RL-V2 для русского. Общий Vocos, существующие worker, скачивание, сегментный кеш и монтаж. Нового UI/framework/server нет; Gradio из зависимостей официального F5-пакета не запускается. Extra `f5` устанавливается отдельно. Совместимость `cached-path` требует Hub <2: в lock закреплён стабильный Hugging Face Hub 1.33.0 вместо 2.4.0. Настоящая загрузка Vocos 54 366 452 байт на Hub 1.33 прошла с прогрессом и закреплённой ревизией; обычный offline suite также прошёл.

Размер F5/ESpeech включает vocab; Vocos скачивается один раз и переиспользуется. Все веса установлены через настоящую очередь в общий пользовательский кеш вне приложения.

## Голосовые образцы

CLI `tts voice list/set` и UI вызывают один сервис. Проверяются PCM16 WAV, длительность 2–20 секунд, размер до 10 MiB, непустая точная расшифровка, отсутствие пустого/обрезанного аудио. Профили по языку и роли хранятся вне приложения. При submit WAV копируются в проект с относительными путями; job фиксирует SHA-256, текст и настройки. Перенос закрытого проекта и смена глобального профиля не меняют сохранённые входы. Ключ кеша учитывает образец конкретной роли и расшифровку; проверено переиспользование неизменного guest после замены host.

В браузере проверены выбор ESpeech, загрузка синтетического WAV, сохранение расшифровки, восстановление после reload, повторное сохранение без re-upload и готовый аудиоплеер. Оба новых пресета проверены в AppTest. Ключ UI учитывает изменения образцов. Пользовательские аудио и реальные голоса не использовались: образцы взяты из собственных синтетических записей Qwen предыдущих проверок.

## Настоящий синтез

Синтетический отчёт о мосте и вручную подготовленный диалог двух ведущих; вызовов текстовых LLM нет. Все neural вызовы выполнены с `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`. Загрузчик явно читает локальный vocoder; точный transcript исключает ASR и скачивание Whisper. Автоматический RUAccent не подключён; в ESpeech допускается ручная разметка `+`.

| F5-TTS v1, EN | 9.05 | 35.053 |

Повтор с сохранёнными внутри проекта образцами переиспользовал обе реплики. После изменения только host: F5 — 9.914 с аудио / 20.149 с рендера, ESpeech — 9.743 с / 22.237 с; guest переиспользован, host синтезирован заново. Время включает загрузку движков и прогрев; это smoke test, не сравнительный бенчмарк. MP3 проверяются полным декодированием FFmpeg. Предупреждения о расхождении с минутной целью оставлены: короткий ручной сценарий не растягивается.

Прежний Qwen3 0.6B также реально отработал в обновлённом окружении: 7.53 с аудио за 17.296 с, без сети.

Итоговые проверки: **230 offline-тестов**, Ruff, проверка wheel. Веса, WAV, MP3 и пользовательские настройки не входят в Git. Качество произношения требует прослушивания; длинные выпуски и серии остаются в M2.
