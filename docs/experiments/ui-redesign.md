# Переработка рабочей области brofessor

02.11.2026. Реализация одобрена пользователем после [UX/UI-аудита](ui-review.md) и просмотра концепции. Единственный список задач — [план реализации](../implementation-plan.md).

## Что изменилось

Главный экран — проект и его результаты. В боковой панели остались выбор проекта, язык и четыре раздела: результаты, источники, заметки, настройки. Текстовый исполнитель, диагностика, скачивание моделей речи и образцы голосов находятся в настройках; форма создания показывает выбранного исполнителя и границу передачи текста. У сценария видны выбор модели речи и ограничения произношения. Убрана рекомендация попробовать Silero вместо Qwen: русский Silero-пилот получил отрицательную оценку пользователя.

Результаты названы по содержанию и открываются автоматически после отправки. Есть поиск, фильтр и страницы списка. Сценарий объединён со своими файлами; уточнения и выпуски доступны через связанные результаты. Поиск учитывает названия дочерних результатов. Группировка использует прежние метаданные, миграции БД нет. Активная обработка видна в любом разделе, ошибки, отмена и явное продолжение сохранены.

Обычный режим показывает читаемый текст, реплики, слайды, таблицы и шаги. Редактор предлагает поля ответа, реплик, слайдов, таблиц, заметок докладчика, плана серии и терминов. Ссылки на оригинальные фрагменты остаются доступны. JSON вынесен в дополнительный режим; сохранённые редакции можно отдельно прочитать и скачать. Источники просматриваются по одному фрагменту, заметки — по одной выбранной записи.

Несохранённые поля остаются при переходах между разделами, языками и проектами в текущей сессии. Сохранение по-прежнему проверяет ожидаемую редакцию и создаёт новую. Рендер заблокирован при несохранённом или устаревшем буфере. Общий `service.render(revision=...)` фиксирует номер показанной сохранённой версии; CLI получил такой же `draft render --revision`. Конкурентная правка через CLI не меняет текст уже отправляемого рендера. Выбор готового файла показывает редакцию, статус, модель и время; рядом указана текущая версия сценария.

Визуальная часть: спокойный синий акцент, компактный бренд, заголовок проекта, выделение выбранного результата, единая плотность и ширина текста. Использованы native Streamlit и CSS собственных HTML-классов/документированных контейнеров `st-key-*`. Внутренние DOM-селекторы Streamlit не используются. Тема задана локально в проекте и аргументах запуска установленного CLI; новый framework и пакеты не добавлены.

## Фактическая проверка

- Полный offline suite: **362 passed in 26.45s**. Ruff check и format проходят, `git diff --check` чистый.
- AppTest проверяет чтение без основного JSON, блокировку несохранённого рендера, сохранение полей после навигации/смены языка и новую редакцию без потери старой. Проверены добавление пустого слайда, переходы между родителем и уточнением, поиск выпуска серии. Прежние проверки идемпотентности, конфликтов, проектов, отмены и восстановления адаптированы к новой навигации, их поведенческие проверки сохранены.
- При контролируемой конкурентной правке UI закрепляет r1, хотя последняя редакция уже r2. Отдельная CLI-проверка действительно собирает PPTX из r1 после сохранения r2 и читает текст слайда. Правки таблицы с изменением числа столбцов и схемы из UI доходят до native-объектов PPTX и notes через CLI.
- Настоящий Streamlit проверен на `127.0.0.1:61440` с отдельным `XDG_CONFIG_HOME` и существующим синтетическим QA-проектом. В браузере открыты ответ с оригиналом, презентация, сценарий с аудиоплеером, источники, заметки и настройки. Проверены RU↔EN, несохранённое поле слайда после перехода между разделами, блокировка PPTX, чтение изменённого ответа и явное возвращение сохранённой версии. Пробные тексты не сохранялись. Новых текстовых вызовов, синтезов и скачиваний весов не было.
- На ширине 390 px проверена вертикальная компоновка, `scrollWidth == clientWidth == 390`; override затем снят. Это smoke test доступности содержимого, полноценный мобильный UX отдельно не оценивался.

Локальные материалы, исключённые из Git: `outputs/ui-redesign/final-tests.log`, `final-targeted.log`, `workspace-ru.jpg`, `structured-editor-en.jpg`. Снимки относятся к настоящему приложению. Временный QA-сервер остановлен после проверки; пользовательские UI/Ollama и глобальные настройки не менялись.

## Границы результата

Несохранённый буфер живёт в UI-сессии; закрытие/обновление браузерной сессии не заменяет явного сохранения. PPTX в UI представлен текстом и native-таблицами/шагами, точного изображения слайда нет. Мобильная версия использует вертикальную компоновку Streamlit. Оценка удобства самим пользователем ещё впереди. Качество русского произношения не исправлялось этой переработкой, слуховая приёмка M4 остаётся открытой.
