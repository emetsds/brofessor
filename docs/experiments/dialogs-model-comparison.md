# Сравнение Fish, OmniVoice и VoxCPM2 с Димой и Светой

Пользователь одобрил короткие Fish/Dialogs-пробы Димы и Светы, затем поручил сравнить движки с этими референсами. Этот опыт создаёт записи для прослушивания; победитель и новый дефолт не назначены.

## Материал и условия

Общий исходник — прежняя проверенная редакция начала I части «Дамы с собачкой» Чехова с ё; около 800 слов. Те же 23 последовательных фрагмента и чередование Дима/Света у каждого движка. Между фрагментами добавлено 0,25 с; словесное содержание не сокращалось. Это непрерывный книжный материал, собранный из вызовов на фразы, а не один пятиминутный вызов модели.

Референсы — прежние полные Dialogs neutral Дима (11,19 с) и Света (11,43 с), revision `a74ff44d8d27ca3d21098ea3ed4d31a32923fbdd`, с точными расшифровками. Dialogs OpenRAIL, атрибуция, опубликованное согласие актёров и условия сохранены рядом. Пользователь разрешил личный некоммерческий опыт. Исходники и прошлые результаты не заменены.

Проверенная + разметка сохранена как `pronunciation-key-plus.txt`, но не подавалась этим LLM TTS без подтверждённого контракта поддержки: ударения в записи предсказывают движки. Эта запись не считается ручной слуховой приёмкой произношения.

## Фактические модели

- Fish: `majentik/fishaudio-s2-pro-MLX-4bit@dda28aa6e33fe946826792e3feb643e9c463b75f`, прежний codec из `mlx-community/fish-audio-s2-pro-8bit@c8d4481b3f7cbfe64d855c8b7cda7739502fc3ff`, BF16 с weight-norm folding. Реиспользованы проверенные VQ-коды полных опор; native reference conversation. Прежняя изолированная loader-поправка разрешает реальные quantized embedding/fast layers при строгой загрузке. Temperature/top_p 0.7, top_k 30, speed 1, stream 1 с.

- OmniVoice: `mlx-community/OmniVoice-bfloat16@6119f7072580cc30c3cbdf496269216b03ad9742`; явно скачано 2 042 327 608 байт, веса и codec проверены по upstream LFS SHA-256, малые файлы по Git/LFS hashes. BF16 семантика + FP32 Higgs codec (типы проверены в safetensors), 32 шага, guidance 2, язык ru. Native preprocessing: resample, RMS boost и удаление тишины, без обрезки слов; ref transcript сохранён. В установленном MLX generic duration fallback использует фиктивный английский reference; здесь штатный `RuleDurationEstimator` получает фактический темп наших ref tokens и точный текст. Никакого последующего изменения скорости аудио. Полные опоры немного длиннее рекомендованных авторами 3–10 с, это записано явно; сравнение с более короткими ещё не делалось. Первичная карточка с CC-BY-NC и лицензия кодека сохранены.

- VoxCPM2: `mlx-community/VoxCPM2-8bit@d52725898a0675703f7f9ddc5a4d1a3cdbb99032`, прежние локальные веса. 10 inference timesteps, cfg 2. Native continuation через `prompt_audio` + `prompt_text`; generic `ref_text` этим runtime игнорируется и вместо native prompt не используется. Прежние обрывы на длинном text-only/синтетическом anchor не выдаются за свойства нового полного опыта с настоящими референсами.

Все модели — установленный MLX-Audio 0.6.3 / MLX 0.32.4 на Mac M4 32 GiB. Во время инференса HF/Transformers offline и запрет socket.connect; никаких облачных вызовов. В начале `/api/ps` Ollama вернул пустой список; unload/stop/reconfiguration не выполнялись. Несколько собственных GPU-процессов работали одновременно, поэтому wall time и peak MLX ниже — наблюдения этого опыта, не чистый сравнительный benchmark. Seed 42 + номер фрагмента, одинаковый у движков.

## Файлы и проверки

| Движок | Длительность | Сумма времени сегментов | Peak MLX |
|---|---:|---:|---:|
| Fish S2 Pro 4-bit + BF16 codec | 5:32 | 18:57 | 5.18 GB |
| OmniVoice BF16 | 5:12 | 10:03 | 4.88 GB |
| VoxCPM2 8-bit | 5:06 | 21:38 | 9.16 GB |

Только синтез в основных MP3, без исходников актёров в начале. Общее loudness target, постоянное усиление, без компрессии/EQ/изменения высоты/темпа, resample 48 kHz. Измеренные LUFS, timeline, хеши и полное FFmpeg-декодирование находятся в manifest. Сырые сегменты, model specs, журналы и варианты сохранены в `outputs/dialogs-model-comparison-2026-11-02/`.

[Плееры полных записей](../../outputs/dialogs-model-comparison-2026-11-02/listening-guide.md) · [Короткое сравнение](../../outputs/dialogs-model-comparison-2026-11-02/short-listening-guide.md). Короткий Fish-контроль взят из прежде понравившихся файлов; короткие OmniVoice/VoxCPM2 созданы заново.

Все 69 фрагментов проверены закреплённым локальным Whisper base на примерное покрытие текста. ASR расходится на именах, окончаниях и раздельном написании слов; транскрипты подозрительных мест рассмотрены отдельно и записаны в `asr-review.json`. ASR не принимает ударения, перенос тембра и комфорт длительного слушания.

Код приложения, каталог моделей, пользовательские дефолты и работающие серверы не менялись. Проверены компиляция изолированных скриптов и `git diff --check`; продуктовые offline-тесты не повторялись для генерации медиа. M4 остаётся открыт до слуховой оценки пользователя.

Dialogs — Ilya Shigabeev and Ilya Latyshev (Langswap). Built with Fish Audio.
