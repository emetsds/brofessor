# Первый рабочий срез

Проверено 01.11.2026 на Apple M4 / 32 GB. Использована только собственная синтетическая глава `tests/fixtures/chapter.md`. Реальные пользовательские книги и платные API не использовались.

После этого прогона PPTX-рендерер заменён на `python-pptx`, зависимости Node/npm удалены. [Проверка новой реализации](python-pptx.md) зафиксирована отдельно; ниже сохранена история первого среза.

## Выполнено

- Из главы через официальный Codex CLI 0.162.1 с ChatGPT-входом созданы ответ, русский двухголосый сценарий и план четырёх слайдов. Все ссылки разрешаются в сохранённую исходную главу.
- Повторный настоящий вызов после изменения управления процессами ответил, что данных об углеродном следе нет. Он сохранил `evidence_status=insufficient_evidence` и указал, что пример вымышленный.
- План отрендерен PptxGenJS в PPTX. Четыре страницы просмотрены после QA-конвертации: текст не обрезается и не перекрывается, notes и ссылки присутствуют. QA использует доступный LibreOffice, продукт от него не зависит.
- Через настоящий браузер проверены источники, статусы заданий, редактор и сохранение пользовательской правки названия слайдов. UI показал новую revision2 и скачиваемый draft-r2.json. AppTest отдельно проверяет сохранность несохранённого текста при конкурентной правке из CLI.
- Первый сценарий 398 слов дал 314.97 с аудио за 106.38 с локального синтеза. При запросе 180 с приложение верно отметило несоответствие, вместо выдачи расчётного времени за измеренное.
- После калибровки сценарий сокращён до 260 слов. Одна реплика достигла предела генерации. Задание завершилось с ошибкой, незаконченный сегмент не был опубликован. Правка через общий сервис разделила реплику, сохранив текст и ссылки. Повторная сборка переиспользовала четыре сегмента и создала пять новых: 203.2 с аудио за 35.304 с.
- Отмена, тайм-аут и принудительное завершение worker проверены на собственных тестовых процессах. Отдельный короткий процесс-наблюдатель завершает принадлежащую CLI группу при смерти worker, не пытаясь убивать сохранённые PID. Завершение задания транзакционно учитывает конкурентную отмену.

## Интеграции

| Исполнитель | Фактический статус |
|---|---|
| Codex | Offline contract tests и настоящая генерация через подписку выполнены |
| Claude Code | Offline contract tests и наличие подписочной авторизации проверены, настоящая генерация ещё не проверена |
| Ollama | Offline HTTP contract tests выполнены. Сервер на этом прогоне не работал, настоящая локальная модель текста не проверена |
| Qwen3-TTS / MLX | Настоящие RU/EN образцы, локальная сборка, декодирование и возобновление выполнены. См. отдельный media.md |

На целевом Mac первым в PATH оказался повреждённый Codex wrapper. Для проверки использован установленный стабильный бинарник через `BROFESSOR_CODEX_BIN`. Глобальный PATH не менялся. Веса и зависимости устанавливались отдельно от Git, без пользовательских секретов.

## Границы результата

Технические проверки не подтверждают качество ударений и тембра. Даже после калибровки 203.2 с превышают запрос 180 с на 12.89%, и предупреждение остаётся видимым. Следующий этап должен обеспечить содержательную корректировку длительности, проверить настоящую большую книгу, серии и долгие выпуски. Полный v1 не объявляется готовым.

UI пока редактирует структурированный JSON. Переносимое изображение-превью слайдов, отдельные заметки, многошаговый диалог и полная матрица интеграций остаются в плане. Код первого среза сохраняется и развивается дальше, отдельной заменяемой реализации нет.
