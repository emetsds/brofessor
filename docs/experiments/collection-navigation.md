# Каталог документов и Obsidian без Pi

05.11.2026. Этот отчёт фиксирует первоначальную регистрацию каталога по одному пути и отбор оригиналов через собственный контроллер версии 1. Использованы прежние Python core, bounded text adapters, SQLite, OS-locked worker и checkpoints. В этом опыте Pi и новый агентный framework не устанавливались, проба Pydantic AI Slim ещё не выполнялась. Последующая [проверка и замена цикла на Pydantic AI](pydantic-navigation.md) описаны отдельно. Результаты ниже относятся к первоначальному контроллеру и сохраняются как его история.

## Пользовательский путь

В Sources → Add materials указать путь к каталогу документов или vault и подключить его. Либо `brofessor source add /path/to/vault`. Подключение сохраняет путь/ID, не обходит файлы, не извлекает текст и не вызывает модель. На новой задаче коллекция выбрана по умолчанию; пользователь задаёт промпт и формат результата. Например: «Найди результаты текущего эксперимента River, условия и ограничения; отличи предыдущий прогон». Файлы вручную отбирать не нужно.

Во время задачи модель выбирает структурированные действия: обзор, локальный BM25-поиск, чтение исходных фрагментов, исходящие/обратные ссылки, завершение. Приложение выполняет их в пределах выбранных корней. Поддержаны UTF-8 Markdown/TXT, текстовые PDF и EPUB прежнего импортёра. Для Obsidian добавлены wiki links, inline relative Markdown links, заголовки, block references, aliases, tags и backlinks. Неоднозначная ссылка не разрешается молча.

История навигации, выбранные пути и оригиналы доступны в деталях задачи и через `job sources JOB_ID`. Сохранённые цитаты/рендер работают после изменения, перемещения и отключения каталога. Новый запуск обходит текущие документы. Состав файлов фиксируется при старте задачи; байты каждого файла — при первом обращении. Это не общий атомарный снимок диска.

## Контракты и сборка

`tests/test_collections.py` проверяет границы поведения: подключение без чтения; навигацию по индексу и ссылке; точные исходные цитаты; передачу выбранного Codex/Claude/Ollama adapter; новую версию файла в новой задаче и старые цитаты; resume после отказа автора даже без каталога; отмену в ходе навигации без повторения принятого модельного хода; symlink/path escapes; aliases/headings/backlinks/неоднозначность; обычные PDF/EPUB/TXT; одинаковые байты по нескольким путям; отключение и follow-up scope; запрет ложного full-read при непрочитанных файлах или недоступной подпапке; атомарный отказ read по бюджету; локальную сборку слайдов после удаления каталога; CLI/UI с одним путём; конкурентную миграцию schema 3 → 4 с сохранением данных.

В общей схеме 4 появились регистрации коллекций и `sources.hidden`; прежние источники, задания и редакции сохранены. Конкурентная миграция защищена транзакцией. Кешированные оригиналы не подмешиваются к новым задачам и ручному поиску как самостоятельные источники; явный повторный импорт делает источник видимым.

Полный итоговый прогон: **587 passed**, включая **22** случая каталога. Ruff check/format и `git diff --check` проходят. Результат записан в implementation-plan.md. Wheel реально собран offline и проверен как ZIP: новые модули присутствуют, METADATA закрепляет `PyYAML==6.0.3`. Лицензия установленной версии PyYAML — MIT по её distribution metadata; код/ресурсы библиотеки в репозиторий не копировались.

## Границы

- Поиск лексический, без embeddings. Он локально извлекает и кеширует подходящие по области файлы во время задачи; нет обязательного индекса/конспекта при подключении.
- Не более 100 000 поддержанных файлов, 32 MiB текста в поисковой области, 24 модельных ходов, 48k символов navigation context и 80k выбранных оригиналов. При превышении нужно сузить каталог/промпт; принятую работу сохраняют checkpoints. Это не обещание прочитать огромное хранилище за один вызов.
- Для запроса полного чтения модель задаёт `exhaustive` и область; host проверяет все извлекаемые фрагменты до finish и сообщает непрочитанные. Недоступная подпапка/оригинал не допускают полного завершения. Селективный поиск такой гарантии не имеет.
- Скрытые/системные каталоги, symlinks и неподдержанные форматы исключены. Код и Obsidian/Dataview-плагины не исполняются. Внешние ссылки не открываются. OCR и надписи растра отсутствуют.
- Snapshot документов относится к моменту первого чтения каждого файла. Изменение каталога во время задачи не делает снимок атомарным.
- Реальные проверки навигации Claude/Ollama, большой личный vault и общий benchmark качества не выполнены. Существующие contract tests адаптеров не заменяют такую приёмку.
