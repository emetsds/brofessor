# EPUB 2/3 и целая книга в читалке

04.11.2026. Продолжение P1 после [контекстной терминологии](book-terminology.md). Зависимостей приложения не добавлено; EPUB.js, JSZip и EPUBCheck используются только для QA.

## Изменения формата

Поддержаны reflowable EPUB 2.0 с NCX и EPUB 3.x с XHTML navigation и дополнительным NCX. Сохраняются spine, вложенная структура NCX, цели переходов, ресурсы и исходные XML-префиксы. Переводятся docTitle/navLabel и названия guide; dtb:uid согласуется с новым идентификатором OPF. Имена в docAuthor сохраняются.

Стандартные объявления XHTML 1.0 Strict/Transitional, XHTML 1.1, HTML и NCX разрешены по закрытому списку. Внешние DTD не читаются; именованные символы XHTML разрешаются однократно стандартной таблицей Python. Внутренние подмножества, определения сущностей и неизвестные DTD отвергаются, в том числе в UTF-16. Сохраняются смысл CDATA, комментарии, namespace scopes и QName-значения метаданных. Fixed layout, scripted content, media overlays, шифрование/обфускация и подписи по-прежнему отклоняются.

Обнаружен дефект прежней сборки: EPUBCheck принимал EPUB 3 с добавленными ElementTree префиксами, но EPUB.js 0.3.88 оставался на открытии архива без оглавления и содержимого. Локальная пересборка принятой редакции новым сериализатором открылась: четыре пункта оглавления, кириллица, таблица, SVG, MathML и код. Повторного инференса не было. Регрессионный тест проверяет сохранение исходного написания XML-тегов, дополнительно к namespace-expanded дереву.

Старая вёрстка с длинным `<big>` и абзацами через двойной `<br>` делится для модели по абзацам, без изменения XML. Проекция 2 добавляет это разбиение и исключения лицензии. Проекция 3 дополнительно защищает текстовые вызовы `square(...)`, `cube(...)`, `square_root(...)`, `cube_root(...)` как неизменяемые фрагменты. Новые задания фиксируют `epub_projection=3`. Исторические jobs без параметра используют проекцию 1; jobs проекции 2 сохраняют её. Render, терминологическая правка и regenerate не перепроецируют принятые блоки, словари и редакции.

В новой проекции `epub:type="copyright-page"` и явно обозначенные pg-boilerplate `pg-header`/`pg-footer` сохраняются на исходном языке. Список исключений записан в метаданных EPUB-артефакта; UI сообщает их число. Произвольные непромаркированные юридические разделы автоматически не распознаются.

## Чтение, интерфейсы и ограничения

В EPUB.js открыта именно ZIP-книга r2: обложка, переход из spine, начало (экран 7), середина/`cube_root` (60–61), конец/единицы (88), NCX-переход к исходной лицензии (92). Все **61 изображения основного XHTML** загрузились, битых нет; плюс отдельно проверенная обложка. У исходной книги в NCX только один пункт лицензии — сохранён он, новые авторские главы не выдумывались. Экранные номера относятся к конкретной ширине/высоте.

Узкая проверка использовала колонку reader шириной 390 px, фактическую область книги **370×555 px**: переносы читаемы, перелистывание работает, максимальная отображаемая ширина изображения **340 px**, битых изображений нет. Полный мобильный UI приложения этим не заявляется. Для EPUB 3 дополнительно проверены четыре пункта оглавления, таблица, SVG, MathML, код и переход к сноске/обратно. Скриншоты — `reader-start.jpg`, `reader-middle.jpg`, `reader-formulas.jpg`, `reader-end.jpg`, `reader-ncx-license.jpg`, `reader-narrow.jpg`, `reader-synthetic-*.jpg`.

Настоящий Streamlit показал r2, исходные фрагменты, словарь, два сохраняемых notices и скачивание; загруженный через кнопку файл совпал по SHA-256. Шаг скачивания через браузерный инструмент занял примерно 30 минут: screenshot сохранён в 18:00:10 UTC, файл появился в Downloads в 18:30:11 UTC. Прямой GET штатного media endpoint того же Streamlit вернул все 3 654 693 байта с правильным SHA за **0,075 с**. Повторное нажатие без ожидания download event вернулось за **0,420 с**, но новый файл в Downloads не появился. Это указывает на браузерный этап QA, однако точная причина не установлена и полное время скачивания не принято. Замеры отделены от 16:29 worker; `ui-ready.jpg`, `download-qa.json`, `http-download-qa.json`, `download-retry-qa.json` фиксируют результат. Исправлена также локальная пересборка уже существующего EPUB: Build EPUB остаётся доступна, а оба клиента предпочитают последний доступный экспорт выбранной редакции. Старый неоткрывающийся EPUB можно пересобрать без перевода. Добавлен отсутствовавший русский label для состояния render EPUB.

**199 целевых offline-тестов прошли**: EPUB/XML safety и namespaces, старые проекции, plain math, поздний словарь, core/worker/recovery, CLI/UI и локальная пересборка без повторного инференса. Ruff check/format и diff check проходят. Дорогая граница модели в тестах подменена; реальные восемь вызовов описаны отдельно. Проект и QA используют отдельные XDG-папки; незавершённых QA jobs нет.

Ограничения остаются существенными: автоматический словарь не гарантирует исчерпывающие употребления/anchors, поэтому unanchored фразы не участвуют в точечной коррекции. Грамматика за границей исправляемой фразы, весь класс plain-text математической нотации, длинные современные учебники и конкретные аппаратные читалки не приняты. Надписи растровых картинок/обложки остаются исходными. Первую вычитанную книгу можно читать, но качество полного автоматического результата текущих правил требует отдельного контроля. PDF и озвучка не выполнялись.

Первичные контракты: [OPF 2.0.1 / NCX](https://idpf.org/epub/20/spec/OPF_2.0.1_draft.htm#Section2.4.1), [EPUB 3.3](https://www.w3.org/TR/epub-33/), исходный код закреплённого EPUB.js. PDF и озвучка в этом этапе не проверяются.
