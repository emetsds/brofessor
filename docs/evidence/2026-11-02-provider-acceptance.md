# Приёмка M4: интеграции, установка и перенос проекта

Исторический отчёт. Действующие требования и границы — в [спецификации](../specification.md); решения и отмены — в [Decision log](../decision-log.md). Упоминания следующих этапов описывают состояние на дату опыта.

Проверено 02.11.2026 на Apple Silicon Mac с 32 ГБ памяти. Это техническая приёмка и проверка небольшого контрольного материала. Готовность произвольного сценария к публикации без редактора не установлена.

Codex использовал `--ignore-user-config`, отключённые инструменты/web и read-only sandbox; Claude — `--safe-mode`, пустой набор tools, отключённые slash commands/MCP и отсутствие постоянной сессии. Не использовался `--bare`, сохраняющийся API billing или новая авторизация. Учётные файлы не читались, токены не копировались. Для Codex потребовался явный `BROFESSOR_CODEX_BIN` на стабильный официальный бинарник: первый `codex` в PATH оказался другой обёрткой.

Проверены и сохранены неудачные локальные попытки:

- `qwen3:4b-instruct-2507-q4_K_M`, digest `0edcdef34593eac1…`, около 2,5 ГБ: объекты цитат внутри `citations`, затем склейка несмежных предложений. Валидация отклоняла ответы до сохранения. После уточнений два ответа прошли; долгую генерацию трёх слайдов отменили.
- `qwen2.5:7b-instruct-q4_K_M`, digest `845dbda0ea48ed74…`, около 4,7 ГБ: сначала добавленные номера строк в ID. После уточнения ID стали корректны, но слайды и сценарий смешивали русский, английский и китайский, содержали неточные выводы. Структурно валидный результат не принят как пригодный контент; озвучка не выполнялась.

Две скачанные небольшие модели оставлены в обычном кеше Ollama вне Git. Успех адаптера не означает пригодность любых установленных весов. На этом материале маленькие модели не стали надёжным профилем для русского сценария.

## Исправления по результатам проверки

Общий промпт явно разделяет bare fragment IDs, локаторы и дословные цитаты; для несмежных отрывков требуются отдельные quote objects. Язык назван словами и распространяется на заголовки, пояснения и диалог. Строгие проверки ссылок и оригинальных подстрок сохранены; автоматического исправления выдуманных ID/цитат нет.

Ошибка неизвестного ID теперь сообщает количество и способ исправления, не копируя произвольный текст модели в job error/лог. Это закрывает обнаруженный случай, когда вместо ID приходила строка с содержимым цитаты. Добавлен регрессионный тест.

Ollama preflight использует `thinking.values` из `/api/show`. Если конкретная модель явно допускает булево `false`, запрос получает `think: false`, что также видно в doctor. При отсутствии метаданных, строковых уровнях без `false` или некорректных значениях остаётся модельный default. Подмены модели или провайдера нет. У установленной 27B default был `medium`, поддерживался `false`; после изменения ранее не завершавшийся сценарий получен. Это выбор режима ограниченного текстового задания, а не доказательство сохранения качества на всех задачах. Основание: [документация thinking](https://docs.ollama.com/capabilities/thinking), [Chat API](https://docs.ollama.com/api/chat).

## Локальные файлы и запрет внешней сети

Существующий пользовательский Ollama на 11434 не менялся: он сообщал включённое облако и был отвергнут проверкой brofessor. Для эксперимента поднят отдельный сервер на случайном loopback-порту с `OLLAMA_NO_CLOUD=1`, контекстом 32768, q8 KV cache и одним одновременно загруженным экземпляром. `/api/status` подтверждал отключённое облако; `/api/ps` — контекст и локальную загрузку модели. Официальные настройки: [Ollama FAQ](https://docs.ollama.com/faq).

После загрузки зависимостей/весов и клиент brofessor, и отдельный сервер Ollama запускались под временным macOS `sandbox-exec` profile: разрешён только localhost, прочие сетевые соединения запрещены ОС. Контрольный connect к внешнему адресу получил EPERM/EACCES, локальный status продолжал работать. В этом профиле выполнены локальная генерация 27B, сборка PPTX, Silero и полное декодирование MP3. Для клиентского процесса Codex/Claude binaries указывали на несуществующие пути; TTS работала с установленными весами и offline-переменными Hub. Скрытый cloud/API fallback не использовался.

Профиль — временный инструмент QA, не зависимость продукта. Системные настройки, пользовательские серверы и UI на 8501 не менялись. Это проверка выбранного профиля, а не sandbox для произвольного приложения пользователя или обещание отсутствия любой активности других процессов Mac.

PowerPoint и Google Slides в этом прогоне не открывались.

## CLI/UI и независимая жизнь задания

Матрица общих операций проверяется `test_interfaces`, `test_note_interfaces`, `test_ui_language`, `test_projects`, `test_series`, `test_workspace` и `test_worker`: проекты, импорт/оригиналы, поиск/ответы/follow-up, notes/draft revisions, модели/порты/голоса, серия, рендер, артефакты, конфликты и конкурентные операции. Настоящие длинные медиа и редактура проверены в отчётах M2/M3; все веса и сценарии не генерировались заново ради M4.

В отдельном Streamlit на временном порту, с отдельным файлом настроек, проверены выбор проекта вне приложения, local provider/model/port, отправка вопроса и повтор той же формы с тем же job ID. Отмена из CLI появилась в UI как Cancelled; явный Resume и reload сохранили задание и его параметры. Неудачный ответ маленькой модели показан как ошибка, draft не опубликован. Готовый Codex MP3 из CLI-проекта виден с голосовой моделью, покрытием, плеером и фактическими 1:01 при цели 1:00; файл действительно скачан через браузер, а не только показана кнопка.

В отдельном большом синтетическом источнике проверен настоящий Ollama job: CLI отменил работающую генерацию, незавершённый draft отсутствовал. После явного продолжения сохранён checkpoint поиска; наш worker принудительно завершён SIGKILL. Новый worker отметил job как interrupted, UI показал Resume. Продолжение из UI, refresh и закрытие временной вкладки не остановили работу: CLI затем увидел succeeded. SHA-256 checkpoint поиска сохранился; после него сервер зарегистрировал только один успешный `/api/chat` для ответа, без повторного модельного поиска. Mtime checkpoint обновляется при повторной валидации, поэтому сам по себе не является признаком повторной генерации. Локальный профиль и параметры job сохранились при sidebar default `codex` после reload.

## Установка, лицензия и сохранность проекта

Из shared clone репозитория создано отдельное Python 3.12.13 окружение через `uv sync --locked --python … --extra ui`; оно не использует пакеты исходного dev-venv. Дополнительно проверены независимое окружение только core+UI и установка extra `silero` с настоящей озвучкой. После загрузки зависимостей новый core+UI environment установлен повторно из кеша без сети. F5 и MLX extras в новых окружениях M4 не переустанавливались; их прежние проверки остаются в собственных отчётах.

Финальный wheel установлен в третье отдельное окружение с точными зависимостями, экспортированными из lock. Установка зависимостей wheel потребовала registry metadata из PyPI; offline runtime проверен отдельно. Все модули wheel побитово совпадают с финальными исходниками, внутри есть MIT LICENSE и `License-Expression: MIT`; материалов, SQLite, аудио и весов нет.

Закрытый Codex workspace с ответами, правками заметки, редакциями сценария, PPTX и аудио скопирован, затем каталог переименован. Все 38 файлов сохранили SHA-256; источники, jobs, drafts, notes и относительные artifact paths совпали, SQLite integrity_check вернул `ok`. Установленный wheel открыл перенесённый проект и собрал новый PPTX из другого рабочего каталога с пустым PATH и запретом внешней сети. Старые абсолютные пути в диагностических audio metadata являются записью первоначального исполнения; UI использует относительный зарегистрированный artifact path.

По выбору пользователя добавлена MIT-лицензия исходного кода и metadata пакета. Она не распространяется на чужие веса, зависимости и материалы. Публикация, push и создание remote не выполнялись.

## Границы приёмки

В чистом core+UI окружении проходят 340 offline-тестов, Ruff check/format и `uv lock --check --offline`. Проверки контрактов используют подставленные ответы, не подписки или веса. Первый холодный запуск AppTest превысил старый лимит 10 с, а повтор занял около секунды; допуск UI-тестов поднят до 30 с. Один функциональный subprocess-тест с лимитом 2 с не уложился во время тяжёлой локальной загрузки; изолированный повтор и окончательный полный прогон прошли без изменения его лимита. Поведение продукта этими допусками не менялось. CI использует Python 3.12 и установку шрифта DejaVu; удалённый GitHub Actions не запускался.

Короткий корпус не устанавливает качество локальной обработки целой книги. На raw drafts всех исполнителей понадобилась редактура; локальный сценарий потребовал существенной переписи. Предложенный порог не более 5% исправляемых реплик в этом коротком случае не подтверждён. Не объявляем полностью принятую генерацию без редактора и не заменяем проверку фактов существованием цитаты.

Техническая работоспособность не подтверждает качество сценария и речи. Последующие содержательные проверки описаны в [длинном Qwen-контроле](2026-11-03-qwen-long-dialogues.md); полная личная слуховая приёмка позднее отменена по D027.

Артефакты приёмки находятся вне Git в `outputs/v1-acceptance/`: проекты и версии, raw JSON синтетических ответов, результаты/журналы, MP3/PPTX, PDF/PNG и скриншот UI. Бинарники, среды и веса в этот каталог не копируются.
