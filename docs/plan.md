# Plan brofessor

Единственная текущая очередь работ. Требования находятся в [спецификации](specification.md), принятые решения и отмены — в [Decision log](decision-log.md).

Блок содержит результат, связанные требования/решения, задачи и проверку готовности. После проверки результата и обновления документации завершённый блок удаляется целиком; существенные отмены остаются в журнале. Исторические evidence не создают новых задач.

На 08.11.2026 согласованных незавершённых блоков нет.
