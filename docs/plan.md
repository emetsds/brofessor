# brofessor work tracking

OpenSpec owns change planning and implementation tasks. Run `openspec list` to see active changes, then read the selected change's `proposal.md` and `tasks.md` under [openspec/changes](../openspec/changes/).

This file is a navigation pointer, not a second task list. The previous plan had no unfinished blocks when OpenSpec was introduced on 2026-11-08.

The existing product baseline remains in [the product specification](specification.md). Accepted OpenSpec capabilities live in [openspec/specs](../openspec/specs/). Historical checks in [evidence](evidence/) do not create new work.
